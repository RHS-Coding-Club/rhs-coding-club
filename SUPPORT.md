# Getting help

- **Questions about the club or joining:** use the [contact page](https://rhs.riponhighcodingclub.workers.dev/contact) or ask on [Discord](https://discord.com/invite/UQR79bn6ZZ).
- **Questions about the code:** ask on Discord or start a [GitHub Discussion](https://github.com/RHS-Coding-Club/rhs-coding-club/discussions). [CONTRIBUTING.md](CONTRIBUTING.md) covers local setup.
- **Bugs and feature ideas:** [open an issue](https://github.com/RHS-Coding-Club/rhs-coding-club/issues/new/choose).
- **Security problems:** report them privately, as [SECURITY.md](SECURITY.md) describes.

This site is run by student volunteers, so replies may take a few days, and longer during school breaks.
